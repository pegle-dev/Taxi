### 문서와 다른 점 (구현 시 문서 기준)

- 이미지는 그라데이션·부드러운 조명이 많다. 문서는 매끈한 그라데이션 금지, 기본 명암 3단계, ordered dithering.
- 01의 선택지 강조는 회백색 바, 03·04는 흰 테두리. 문서는 선택된 것만 밝은 민트색.
- 01의 화자명 태그는 분홍색. 문서의 포인트 색은 민트와 탁한 적색뿐.
- 로고·시계가 상시 표시되어 있다. 문서는 HUD를 가능하면 없앤다.
- 04의 룸미러 속 승객은 얼굴·옷 묘사가 많다. 유령이라면 문서 기준으로 정보량을 더 줄인다.
